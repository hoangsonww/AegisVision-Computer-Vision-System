# Support

> **How to get help with AegisVision.**

AegisVision is authored and maintained by **Son Nguyen**
([@hoangsonww](https://github.com/hoangsonww)). Support is community-style
and best-effort.

---

## Channels

### Questions

**GitHub Discussions** is the preferred channel for questions:

- "How do I deploy this?"
- "What's the right way to wire up X?"
- "Why is the bus subject named that?"
- "Has anyone tried this with backend Y?"

Open one at:
<https://github.com/hoangsonww/AegisVision-Computer-Vision-System/discussions>

### Bug reports

Use **GitHub Issues** with the `bug` template. See [`CONTRIBUTING.md`](./CONTRIBUTING.md).

### Feature requests

Use **GitHub Issues** with the `feature-request` template.

### Security reports

**Do not file public issues.** See [`SECURITY.md`](./SECURITY.md) and
email <hoangson091104@gmail.com>.

### Commercial / consulting / production-deployment questions

Email <hoangson091104@gmail.com> directly. Include:

- Your use case.
- Scale / deployment shape.
- Specific question.

## What you'll get help with

- Setup + first deploy.
- Local walking-skeleton issues.
- Configuration questions.
- Conceptual / architectural questions.
- Bug confirmation + reproduction.

## What is best-effort

- Production deployment debugging (especially air-gapped).
- Custom integration help.
- Long backlogs of "could you add feature X" issues.

## Response times

- Security reports: 5 business days for ack.
- Bug reports: best-effort, typically within a week.
- Discussions: best-effort.
- Email: best-effort.

Please be patient — support is best-effort. If something is urgent
and production-impacting, mention it clearly in the subject.
